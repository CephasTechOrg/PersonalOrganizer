# Project Description

## Purpose

Personal Hub is a private command center for opportunities and actions that would otherwise be lost across chats, bookmarks, email, or notes.

The system is designed to answer one question quickly:

> What requires attention now?

## Primary use cases

- Save an internship, fellowship, program, startup opportunity, funding opportunity, competition, or event.
- Store both an information/source link and a direct application link.
- See opportunities that still need an application.
- See deadlines that are approaching or overdue.
- Mark an opportunity as applied, waiting, interview, accepted, rejected, or archived.
- Add a follow-up date after applying.
- Attach action items to an opportunity, such as "finish essay" or "download transcript".
- Keep unrelated personal action items in the same task system.
- Open the relevant link immediately from the frontend.

## V1 scope

The starter backend provides:

1. Private owner authentication.
2. Opportunity lifecycle management.
3. Task lifecycle management.
4. Search and filtering.
5. Deadline and follow-up fields.
6. Dashboard attention queries.
7. Audit history.

## Non-goals for V1

- Multi-user accounts
- Teams or organizations
- AI opportunity extraction
- Email ingestion
- Calendar synchronization
- Browser extension
- File uploads
- Push notifications
- Automated web scraping

These can be added after the daily workflow is proven useful.
